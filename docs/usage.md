# Notes Manager Usage Guide

This project is a simple Python notes manager.

## Requirements

- Python 3.x

## Running the Program

Clone the repository:

git clone https://github.com/your-username/notes-manager.git

Navigate into the project folder:

cd notes-manager

Run the program:

python src/notes.py

## Example Usage

Add a note:

add_note("Buy groceries")

List notes:

list_notes()

Output example:

["Buy groceries"]

## Running Tests

Run the tests using:

python -m unittest tests/test_notes.py
